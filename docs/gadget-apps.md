# Приложения как файлы проекта Mnemos

ADR 0028 Mnemos, этапы 1 и 2. Этот файл — справка для навыков opencode и для тех, кто пишет гаджеты.

## Формат файла

Тип содержимого узла — `application/vnd.cloudflareos.app+json`, формат в каталоге версий — `cloudflareos.app`.
Тело узла — JSON:

```json
{
  "format": "cloudflareos.app",
  "formatVersion": 1,
  "document": {
    "manifest": {
      "title": "Список дел отдела",
      "description": "Общий список задач",
      "collaborative": true,
      "session": true,
      "formatVersion": 1,
      "permissions": ["directory"]
    },
    "modules": { "client.js": "…", "server.js": "…" }
  }
}
```

Проверка строгая (`workshop-shared/src/gadget-app.ts`): лишние поля и модули — отказ.

- `title` — одна строка, до 120 знаков.
- `description` — до 2000 знаков.
- `collaborative` — `true`: один экземпляр и одна база на файл для всех, у кого есть доступ; `false`: у каждого свой экземпляр.
- `session` — класс `Gadget` объявляет `session(caller)`. Для `collaborative: true` обязателен: общий экземпляр
  отдаёт странице только то, что вернул `session(caller)`, и никогда сам объект `Gadget`. Оболочка ставит признак
  при сохранении, если в `server.js` есть `session(`.
- `permissions` — пока только `directory` (справочник людей и отделов).
- `client.js` — до 2 МиБ, `server.js` — до 1 МиБ, весь файл — до 4 МиБ.

Других модулей нет: сборка кладёт всё в `client.js` и `server.js`. Подключений (bindings) у приложения нет, сети у сервера нет.

## Сервер гаджета: кто вызывает

`server.js` экспортирует класс `Gadget` (Durable Object). Если в нём есть метод `session(caller)`, оболочка
вызывает его один раз на каждое подключение страницы, а страница работает с тем, что он вернул.

```js
import { DurableObject, RpcTarget } from "cloudflare:workers";

class Session extends RpcTarget {
  constructor(app, caller) { super(); this.app = app; this.caller = caller; }
  me() { return { name: this.caller.name, canEdit: this.caller.access === "edit" }; }
  addTask(text) {
    if (this.caller.access !== "edit") throw new Error("Только просмотр");
    return this.app.addTask(this.caller.principal, text);
  }
}

export class Gadget extends DurableObject {
  session(caller) { return new Session(this, caller); }
  addTask(principal, text) { /* this.ctx.storage */ }
}
```

Правила для `session(caller)`:

- не возвращать `this` (сам объект `Gadget`) и ничего, через что страница могла бы вызвать сервер от имени
  произвольного человека;
- каждый метод объекта, который вернул `session()`, берёт человека из сохранённого `caller`
  (`caller.principal`, `caller.access`), а не из аргументов вызова;
- методы класса `Gadget`, принимающие principal аргументом, со страницы недоступны: их зовёт только объект сессии.

`caller` — только данные, без ссылок RPC, хранить можно сколько угодно:

| Поле | Что это |
|---|---|
| `principal` | Устойчивый ключ человека в Mnemos. По нему разделяются данные по людям. |
| `name` | Имя для показа. |
| `access` | `"read"` или `"edit"` — право на файл приложения. |
| `directory` | Есть, только если в манифесте разрешение `directory`: `{ people: [{id, name}], departments: [{id, name, members: [{id, name}]}] }`. Снимок на момент подключения. В общем экземпляре — только то, что видят одновременно открывший и тот, кто с правом правки запустил работающую версию; в своём экземпляре — справочник открывшего. |

Право проверяется оболочкой при открытии, на каждом вызове (полная проверка не реже раза в 30 с) и по
таймеру, пока страница открыта; срок каждой проверки — 10 с. Потеря доступа, понижение права, просрочка
проверки или другой человек, установка или узел в ответе Mnemos закрывают связь; новое подключение
придёт с новым `caller`. Без `session()` работает только приложение без совместной работы (в своём экземпляре).

В предпросмотре правок (рабочее место беседы) `session()` тоже вызывается: `principal` — `workspace:<id
пользователя оболочки>`, `access` — `"edit"`, справочника нет. Данные предпросмотра отдельные.

## Где живёт экземпляр

Durable Object `MnemosAppDurableObject`, два вида ключей из ответа Mnemos о праве (проект и узел — как их назвал
Mnemos, не как их прислала страница), и адрес установки Mnemos — разные установки с совпавшими id не делят
экземпляр:

- общий: `[установка, организация, проект, узел]` — совместные приложения;
- свой: `[установка, организация, проект, узел, principal]` — приложения без совместной работы.

Сервер гаджета исполняется в объекте facet'ом через `LOADER` с `globalOutbound: null` и пустым `env`. Объект
хранит работающую версию (текст узла кусками), журнал открытий и смен кода (последние 500 записей). Новая версия
перезапускает facet; база приложения сохраняется.

В общем экземпляре работает только опубликованная версия узла (прошедшая публикацию и согласование, как у
документа). Личные версии (черновики автора и участников) — только в предпросмотре рабочего места, со своими
данными. Сменить работающую версию может только человек с правом правки («Опубликовать», «Запустить эту
версию»). Без права правки — лишь первый запуск пустого экземпляра последней опубликованной версией; проверка
«экземпляр пуст» и запись делаются в объекте одним шагом. Код версии оболочка читает из Mnemos сама, правами
открывшего; открывший должен иметь доступ к самой работающей версии.

## Кто получает код

С правом правки код версии встаёт в гаджет своего рабочего места: его можно править в беседе, предпросмотр идёт
отдельным экземпляром. Без права правки код в рабочее место не кладётся и в браузер не скачивается: страница
получает только `client.js` работающей версии во фрейм, агент беседы кода не видит, «Сохранить в проект»
для такого гаджета недоступно.

## Открытие

Как у документа: из проекта, «Материалов», уведомлений, «Поделились с вами», ссылки в беседе
(`launchNativeDocument` → `launchMnemosApp`), в Telegram Mini App (экран приложения без сохранения).
У каждого человека своё рабочее место на файл; код версии встаёт в гаджет этого места. Шапка — те же
«Поделиться» и «Версии». Гаджет беседы сохраняется в проект кнопкой «Сохранить в проект…».
